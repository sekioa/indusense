# Documentation de la formation

Cette documentation est organisée par sprint, puis par type de contenu. Les préfixes numériques assurent un ordre stable dans l'explorateur de fichiers.

## 00 — Hors sprint

- `01-referentiel` : programme et livret d'accueil.
- `02-certification` : modalités, kit candidat et exemples de livrables.

## 01 — Sprint 1

- `01-suivi`, `02-revisions`, `03-architecture`, `04-planification`, `05-ressources`.

## 02 — Sprint 2

- `01-cours`, `02-transcriptions`, `03-suivi`, `04-revisions`, `05-consignes`.

Les notebooks sont séparés de cette documentation et se trouvent sous `indusense/notebooks/`, avec la même convention de classement.
